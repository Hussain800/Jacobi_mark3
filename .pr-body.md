## Summary

This mega PR turns the current JACOBI product iteration into a more reliable,
evidence-first, enterprise-safe, and agent-ready product while preserving
honest demo/live boundaries.

## Product and backend

- Added an explicit execution-service lifecycle authority for queued work,
  legal transitions, cancellation, recovery, malformed-claim failure, and
  worker-safe terminal states.
- Added shared probe accounting and evidence adjudication. Inferred/copied
  observations cannot repair coverage, attribution, PEI, quota, or persisted
  evidence.
- Enforced limited-coverage `insufficient_data`, unattributed-spread
  `indeterminate`, and closed PEI gates when evidence is insufficient.
- Hardened enterprise tenant scoping, role/RLS boundaries, exports, share
  revocation, anonymous bearer redaction, retry idempotency, SSRF/redirect
  protection, quota checks, and provider failure behavior.
- Added shared REST/MCP command semantics for Jacobi for Agents, including
  blocked-purchase/no-collection behavior and provenance-safe contracts.

## Contracts, frontend, and operations

- Added versioned API contract schemas, sanitized fixtures, structured errors,
  agent decision expiry, contract tests, and developer documentation.
- Improved cockpit, landing, dashboard, evidence, and portfolio flows with
  explicit demo/live/error/submitting states, honest lifecycle labels,
  inferred-row filtering, and scan-specific finding links.
- Added deployment/readiness documentation, CI/test coverage, extension scope
  labeling, and a Supabase member-insert hardening migration.
- Updated product, architecture, handoff, and research documentation.
